# 13: Seeded replay as the front door

**What to build:** Someone arrives with no API key and no Ollama — an employer, most likely. Right now the app would ask them for a key and they would leave in fifteen seconds. Instead, the landing page opens with a finished match already replaying itself: board animating, thoughts streaming, bots talking, no key required. "Run your own" is the secondary action.

Hosting was never the demo problem; this is (SPEC §10).

Three or four seeded matches, chosen to be genuinely worth watching — a named character against a famous player, GPT against Gemini, something with a dramatic blunder. They cost nothing to serve and cannot break under load, which a funded live demo would.

Replays are public but unlisted: anyone with a link can watch, nothing is enumerable, and a curated gallery lists only matches you pick. No public feed of whatever strangers type into a free-form prompt box on a personal site.

Seeds are regenerated by re-running the script when the stored shape changes. Four rows is not a migration problem, and version-tolerant rendering would be machinery for nothing.
